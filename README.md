# Strabo Website  

A modern and responsive website built for **Strabo** using **React.js** and **Tailwind CSS**. This project showcases clean UI/UX, component-based architecture, and optimized performance for an enhanced web experience.  

## 🚀 Features  
- ⚡ Built with **React.js** for dynamic and fast rendering.  
- 🎨 Styled using **Tailwind CSS** for a fully responsive and modern design.  
- 📱 Mobile-first approach with cross-device compatibility.  
- 🔄 Reusable and scalable components for easier maintenance.  
- ⚙️ Optimized performance with clean code structure.  

## 🛠️ Tech Stack  
- **Frontend:** React.js, Tailwind CSS  
- **Tools:** npm / yarn, Git, VS Code
